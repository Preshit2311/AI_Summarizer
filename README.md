# AI Summarizer 📝

A lightweight web application that summarizes any text quickly using **HTML, CSS, and JavaScript**. Perfect for students, content creators, and developers who want concise summaries in seconds.

---

## 🌐 Live Demo
Check it here: [View on Netlify](https://summm-ai.netlify.app/)  
---

## 💡 Features
- Summarizes large text into concise summaries
- Responsive and user-friendly UI
- Works entirely on the client-side (no backend required)
- Minimal and clean design
- Copy summarized text with one click
